# TFQ-Sales-SQL-Practice

---

## Description

This project demonstrates SQL database creation, data manipulation, and analytical querying using MySQL. The project involves building a relational database containing employee, department, and sales data and applying SQL techniques such as subqueries, Common Table Expressions (CTEs), aggregate functions, joins, and window functions to answer business-related questions.

---

## Project Objective

The objective of this project is to practice SQL querying techniques and develop analytical problem-solving skills by extracting meaningful insights from employee, department, and sales datasets.

---

## Business Questions

### 1. Which employees earn above the average salary of all employees?

### 2. Which employees earn the highest salary in their respective departments?

### 3. Which departments do not have any employees assigned to them?

### 4. Which stores generate sales above the average sales across all stores?

### 5. What is the average salary of employees in the organization?

### 6. What is the total sales generated by each store?

### 7. How can subqueries, CTEs, and window functions be used to solve business problems efficiently?

---

## Key Insights

- Several employees earn above the organization's average salary.
- The highest-paid employees vary across departments.
- Some departments exist in the department table but have no employees assigned to them.
- Store sales performance differs across locations.
- Certain stores generate sales above the overall average sales level.
- Advanced SQL techniques such as subqueries, CTEs, and window functions simplify complex analytical tasks and improve query efficiency.

---

## Recommendations

- Review salary structures across departments to ensure consistency and fairness.
- Assess departments without employees to determine staffing requirements.
- Analyze top-performing stores to identify factors contributing to strong sales performance.
- Apply successful strategies from high-performing stores to lower-performing locations.
- Continue leveraging advanced SQL techniques for efficient business reporting and analysis.
